# Marc Control MCP Personal

[中文](README.zh-CN.md) · [日本語](README.ja.md)

A Windows application connecting WorkBuddy, Codex and Claude Desktop to your local Marc/Mentat through MCP. The commercial source remains private; this repository hosts documentation and reviewed binary releases.

## Release status

Personal 1.2.1 is an online release candidate. HTTPS activation, refresh, device limits and revocation have passed packaged-program acceptance. Real AI-client acceptance remains before public release. Internal test-key packages are development artifacts. See [Releases](https://github.com/WangJ226/Marc-MCP-Assistant/releases) for published builds.

## Workflow

Install the released EXE, request an approved seven-day machine-bound trial from 1309224565@qq.com, activate using your customer ID and code, confirm the detected Marc installation, choose an AI client and copy the prepared first-use prompt.

The application inherits 174 tools from the internal V2.16 baseline. Marc 2016–2025 is the adaptation range; 2024/2025 are recommended. Users supply Marc/Mentat and their license. Execution tools require confirmation. Validation reports describe their actual environment and scope.

## Purchase and renewal

Seven-day trials require manual approval and start at issuance. Paid options are 30 consecutive days and 365 days. Prices are quoted manually. Alipay payment guidance is included; the operator verifies receipt before enabling access. Online leases refresh every ten minutes, with at most one hour of cached access, bounded by the purchased expiry. Contact the operator for reinstall and device migration.

Use Check updates to view published release notes and download an installer. Close related AI connections and upgrade in the original directory to preserve settings. Engineering decisions remain the user's responsibility. This independent product provides MCP software; Marc licenses, manual model debugging and engineering consulting are outside the included service.
