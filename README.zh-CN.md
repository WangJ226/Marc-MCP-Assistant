# Marc Control MCP Personal

让 WorkBuddy、Codex 或 Claude Desktop 通过 MCP 连接本机 Marc/Mentat。

[English](README.md) · [日本語](README.ja.md)

## 当前状态

当前开发候选为 Personal 1.2.1。正式联网安装包将在域名、HTTPS 与正式客户端验收完成后发布到 [Releases](https://github.com/WangJ226/Marc-MCP-Assistant/releases)。带测试公钥的内部包用于开发验收。

## 使用条件与能力

- Windows，客户自行安装 Marc/Mentat 并提供可用许可证。
- Marc 2016–2025 为适配范围，推荐 2024 或 2025；逐版实机验证状态以具体验收记录为准。
- 继承内部 V2.16 的 174 个 MCP 工具；界面提供中文、英文、日文。
- 软件协助自动发现 Marc，配置所选 AI 客户端，并准备首次使用提示词。
- 具有执行能力的工具保留用户确认，工程判断与模型正确性由使用者负责。

## 安装与授权

1. 从 Releases 下载正式安装包和 SHA-256，核对后安装。
2. 联系 1309224565@qq.com，申请人工批准的一次七天单机试用。
3. 收到客户编号与激活码后，在软件中在线激活。
4. 自动检测 Marc，选择 AI 客户端并连接，将准备好的提示词复制到 AI 对话。

付费提供连续 30 天和年度 365 天，金额人工报价。软件内有支付宝付款指引；经营者核实实际到账后开通或续费。试用从签发时刻起连续168小时。

在线版每10分钟尝试刷新，网络异常时使用现有凭证，最长至最近成功验证后一小时；购买期限始终优先。到期后续 MCP 操作需要有效授权。换机和 Windows 重装联系经营者核对办理。

## 更新与边界

通过软件“检查更新”查看正式 GitHub Release，确认后下载安装。更新时关闭相关 AI 连接，选择原目录以保留授权和设置。

本仓库公开使用说明和二进制发行资产，开发源码保持私有。产品为独立开发软件；客户自行提供 Marc/Mentat 软件与许可证。销售内容为 MCP 软件功能，人工排障、模型调试和工程咨询另属用户自己的工作范围。当前尚在完成正式联网发布前验收。
