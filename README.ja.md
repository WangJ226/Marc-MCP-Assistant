# Marc Control MCP Personal

[中文](README.zh-CN.md) · [English](README.md)

Windows 上の Marc/Mentat を WorkBuddy、Codex、Claude Desktop から MCP 経由で操作する独立開発アプリです。ソースコードは非公開で、ここでは説明資料と確認済みの実行ファイルを公開します。

現在 Personal 1.2.1 は開発候補版です。正式オンライン版は独自ドメイン、HTTPS、最終クライアント検証の完了後に Releases へ公開します。

## 利用手順

1. 公開された EXE と SHA-256 を確認してインストールします。
2. 1309224565@qq.com に、手動承認制の7日間・1台限定体験を申し込みます。
3. 顧客番号と認証コードで有効化します。
4. 自動検出された Marc と AI クライアントを確認し、用意された最初のメッセージをコピーします。

内部 V2.16 の174ツールを継承します。対応範囲は Marc 2016–2025、推奨は2024/2025です。Marc/Mentat とライセンスは利用者が準備します。実行操作には利用者の確認が必要です。

料金は個別見積で、連続30日または365日を選べます。Alipay 支払い後、運営者が入金確認して有効化します。体験期間は発行時から168時間です。オンライン認証は10分ごとに更新を試み、保存済み認証は最長1時間、購入期限の範囲内で有効です。再インストール・PC移行は運営者に連絡します。

更新確認から正式 Release の説明とインストーラーを開けます。AI接続を閉じ、元の場所へ更新すると設定が維持されます。工学的判断は利用者が行います。提供範囲は MCP ソフトウェア機能です。
